# Sakshi Shah · Portfolio

My portfolio: **https://sakshishah-dev.github.io/portfolio/**

A clean page for everyone, plus two things for developers:

- **▶ Watch it get built**: the page removes all its styling, then rebuilds itself layer by layer (HTML → layout → type → components → data → interaction), with a caption for each step.
- **X-ray switch**: outlines every component; click one to read its **real source code** (pulled from this repo at build time).

## Stack (₹0 forever)
React 18 · TypeScript · Vite · self-hosted fonts · GitHub Pages · GitHub Actions. No server, no database, no paid services.

## Run locally
```bash
npm install
npm run dev
```

## Add a project
Add one object to `src/content/projects.ts`. Its card and case-study page appear automatically.
